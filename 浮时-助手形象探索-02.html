浮时 · 助手形象探索 02

外壳不动，重做角色。这次先立规范，再画形象　·　两族六个，等你选

01

先把"顶尖"翻译成规则

"好看"不能靠感觉反复试。我读了 Apple 人机界面指南的 Layers / Materials / Motion 三节，和成熟角色 IP 的公开设计方法，抽出八条能直接执行的规则——下面六个形象全部按这八条画。

R1

图层，不是平面

形象由"底层 + 前层"叠出来，靠透明与叠压制造深度；不是一笔平涂。

来源：Apple HIG · App icons / Layer design
R2

边缘干净，细节靠块面

轮廓要清晰利落，别用羽毛边；避免极细的线和尖角——小尺寸会碎掉。

来源：Apple HIG · "Prefer clearly defined edges" / "avoid extremely thin line weights"
R3

一个核心想法

用最少的形状表达一件事。图标越简单，越容易被一眼记住。

来源：Apple HIG · App icons / Design
R4

材质决定高光

镜面高光、折射、半透明能让元素"活"起来——但要克制，只给少数元素。

来源：Apple HIG · Liquid Glass / "use sparingly"
R5

光从同一个地方来

统一光源方向（左上约 35°）。高光、内阴影、接触影三者必须同向，否则立刻显假。

来源：角色设计常规 · 光照一致性
R6

表情从眼睛来，不从嘴来

眼睛 + 眼睑 + 眉决定神情；嘴是最后一道、最小的手段。眼距要拉开、位置上移。

来源：角色 IP 设计法则 · 面部可读性
R7

剪影测试

把形象填成纯黑，还能认出来，才算成立。剪影不过关的形状，细节再多也没用。

来源：角色 IP / 图标设计通则
R8

动效只在有意义时发生

不做常驻往复动画。平静待机，状态一变才给一次性、短促、精确的反馈。

来源：Apple HIG · Motion / Best practices
02

建造系统：三个统一

先把三件"公器"定死——形状网格、光照分层、面部系统。六个形象只是把不同的材质和轮廓套进同一套系统，这样它们看起来才像一家人。

形状网格

120 画布，主形占 80%。关键线取整，光向固定在左上 35°。

光照分层

一个体积要有五层：底色 → 顶部受光 → 环境暗部 → 镜面高光 → 接触影。

面部系统

三层眼睛（主体 + 透光 + 柔高光）、下拉眼睑、淡眉。颜色从材质里取，不贴黑。

03

六个新方案

分成两族：器物（像 macOS 图标，一个核心想法、几何精炼）和生灵（像成熟 IP，有生物感与亲和力）。每张卡的大图是待机态，下面一排是四个状态。

家族 A · 器物 —— 一小段可以被握住的比喻
方案 A

露 · 液滴

一滴悬着的水。半透、折射、内部有自己的光——它本身就是"液态玻璃"的原型。

轮廓上尖下圆的水滴，唯一的"垂坠"剪影
材质玻璃：内折射边 + 顶部软高光 + 底部回光，高光弥散不刺眼
优势与 v4 的 Liquid Glass 外壳同源，最不需要"说服"；深色桌面上最通透
风险玻璃在浅色背景上容易"化掉"；需要靠边缘折射线拉住
方案 B

沙 · 沙漏

一只黄铜框的玻璃沙漏。时间在里面下落，这件事本身就能被看见。

轮廓上下两腔 + 腰颈，剪影是中轴对称的"8"，远处也能认出
材质三材质同框：玻璃（半透）+ 砂（不透明暖色）+ 黄铜（镜面条高光）
状态沙子是天然的进度条：完成时下腔堆满，是唯一的正反馈
风险结构最复杂，小尺寸下腰颈会糊；已放大上腔以保证脸站得住
方案 C

星 · 折纸星

一颗用纸折出来的八角星。有折面、有棱线——它是"计划"最直白的形状。

轮廓八角星对称剪影，唯一全直线外形，辨识度最高
材质纸：八个折面靠明暗两档交替，没有镜面反射，只有一枚软高光
优势放大到桌面摆件也立得住；折面本身就是"层次"，天生不俗
风险纸的质感很吃投影像素；已用一层定向投影把它"抬"起来
家族 B · 生灵 —— 也可以用"活的东西"来陪
方案 D

萤 · 萤火

一只停在桌角的萤火虫。腹部那点光，是"该开始了"的温柔提示。

轮廓圆头 + 圆腹 + 一对半透翅，剪影有"薄"的部位，很轻
材质深色甲壳（哑光）+ 半透翅 + 自发光腹部——三材质对比最丰富
状态腹部亮度就是状态：临期最亮，完成时转暖金，一眼可读
风险发光在小尺寸上会糊成一团；已限制光晕半径并保留清晰甲壳边
方案 E

鸮 · 猫头鹰

一只安静的猫头鹰。夜里不睡、守着时间——这是陪伴感最强的一版。

轮廓蛋形身体 + 两只耳羽，剪影顶部有"破口"，一眼区分于球
材质哑光绒羽：宽而弱的高光、明显的底部暗部，没有镜面
优势面部圆盘 + 大眼，天然亲和；四种表情最好读
风险动物形象最容易被做"幼稚"；用哑光灰米色 + 奔跑/不做腮红压住
方案 F

苔 · 苔玉

一颗养在桌上的苔藓球。它长得慢，但一直在长——正好对应"坚持"。

轮廓圆球 + 顶部一小丛新叶，剪影有"长出去的一笔"，安静但不呆
材质苔绒：无镜面、靠细碎的明暗斑与上缘柔光表现体积，最耐看
优势质地最容易显"高级"；绿色在灰白系统里是天然的一小点生气
风险绿容易跑偏成"廉价卡通绿"；已把饱和度压到 55% 左右

05

面部系统：这次到底改了什么

廉价感的根子在脸。这一版把上一版"黑点 + 白圆点 + 弧线嘴"整个拆掉重建。

  • 眼睛是三层，不是两点。主体深色椭圆 + 下方同色系的"透光层" + 一枚柔边高光（带 1px 模糊）。看起来是"有厚度的眼睛"，而不是贴纸。
  • 眼睛的颜色从材质里取。露是深蓝、沙是焦褐、星是墨、鸮是赭——五官长在角色身上，不是统一的黑色。
  • 眼距拉开、位置上移。这是"成年角色"的比例。上一版小而低的眼睛，是婴幼儿插画的语言。
  • 表情由眼睑承担。专注 = 眼睑压低（scaleY(.56)），临期 = 睁大，完成 = 换成月牙。眼睛不做缩小，只做开合。
  • 眉只做辅助。2.4px 圆头、62% 不透明度，随状态上下移动 4px，负责"思考"和"惊讶"两种语气。
  • 嘴是最后手段。待机只有一道 30% 的淡痕；只有"临期"和"完成"才出现嘴，且只有 2.6px。
  • 明令禁止：纯白圆点高光、粗弧线嘴、腮红、黑色五官。这四样是上一版廉价感的直接来源。
06

我的建议

如果要"最像浮时"：选 A · 露

它和已经定稿的 Liquid Glass 外壳同源，气质完全一致，且是六个里唯一"本身就是材质"的方案。代价是浅色背景下需要靠折射线拉住轮廓。

如果要"最讨喜、最好做动效"：选 E · 鸮

面部圆盘大、四种表情最易读，做眨眼和眼神游移的收益最高。代价是要严格控制材质，别掉进"卡通可爱"。

如果要"最稳、最不过时"：选 C · 星

全直线对称剪影，剪影与尺寸两项测试都是满分，放大到桌面摆件也不俗。代价是个性偏中性，需要靠动效补性格。

也可以两两组合

比如"露的材质 + 鸮的轮廓"，或"星做托盘图标、鸮做悬浮窗主形象"。告诉我你的倾向，我来做组合稿。
